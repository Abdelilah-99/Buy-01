# Buy-01: e-commerce backend (starter)

Starting point of the **Buy-01** e-commerce platform from Zone01: a Spring Boot 4 service skeleton
with the dependencies the platform needs. The complete microservices version (gateway, Eureka,
Kafka, OpenSearch, Stripe) is in [market-place](https://github.com/Abdelilah-99/market-place).

## Included
- Spring Boot 4 web MVC
- Spring Security
- Spring Data MongoDB
- Spring AMQP (RabbitMQ messaging)
- Gradle wrapper

## Run it
```bash
./gradlew bootRun
```

**Stack:** Java · Spring Boot 4 · MongoDB · RabbitMQ · Gradle
